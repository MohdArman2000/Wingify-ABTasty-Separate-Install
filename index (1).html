Dynamic Elements Testing Lab

All widgets below are created in the main document DOM only after you act. They are not hidden in the page source. Close / hide / clear removes them from the DOM. 

Main Document
  └─ #dynamicElementsSection
       └─ empty mount nodes
            └─ form / dropdown / modal / list / tooltip created on activity

No dynamic elements in the DOM yet.

1. Click to render a form

The form does not exist until you click Show Form.

Assert: #dynamicPopupForm is absent until click
Then: #dynamicFormName, #dynamicFormEmail, #dynamicFormSubmit exist

2. Click to render a dropdown

The dropdown and its options are created on click, then option nodes appear when opened.

Assert: #dynamicCustomDropdown is absent until click
Open: #dynamicDropdownMenu and option buttons are created

3. Click to render a native select

A real <select> with option children is inserted only after click.

Assert: #dynamicNativeSelect is absent until click

4. Click to render a modal

Modal markup is created on open and destroyed on close. Not pre-hidden.

Assert: #dynamicModal is absent until Open Modal
Close removes #dynamicModalBackdrop from the DOM

5. Hover to render a tooltip

Tooltip node is created on mouseenter and removed on mouseleave.

Assert: #dynamicTooltipBubble is absent until hover

6. Click to add list items

Each click creates a new <li>. The list itself is created with the first item.

Assert: #dynamicItemList is absent until first Add Item

7. Delayed render (wait test)

Click starts a 1.5s wait, then the result node is inserted. Use this for waitFor / explicit wait tests.

After click: #dynamicDelaySpinner exists
After 1.5s: #dynamicDelayedBox exists, spinner is gone

8. Conditional render

Type open and click Reveal. Wrong text creates an error node instead.

Input "open" → #dynamicConditionBox is created
Anything else → #dynamicConditionError is created

9. Right-click context menu

Right-click the yellow area. Menu nodes are created then removed on outside click.

Assert: #dynamicContextMenu is absent until right-click
Right-click here to render a context menu

10. Click to render a toast

Toast is created on click and auto-removed after 3 seconds, or immediately if you dismiss it.

Assert: #dynamicToast is absent until click, then gone after dismiss / timeout

11. Accordion panel created on expand

Expand creates panel content. Collapse removes it from the DOM.

Assert: #dynamicAccordionPanel is absent until Expand

12. Nested dynamic elements

First click creates a button. Clicking that new button creates a nested card.

Click 1: #dynamicNestedTriggerBtn is created
Click 2: #dynamicNestedChildCard is created

13. Search results rendered on submit

Results list is created only after Search. Empty query creates a no-results node.

Assert: #dynamicSearchResults is absent until Search

14. Radio group rendered on click

Choosing a radio then creates a details box that did not exist before.

Click Show: #dynamicRadioGroup is created
Select a radio: #dynamicRadioDetails is created
